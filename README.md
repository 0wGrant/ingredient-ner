# ingredient-ner

Поиск упоминаний ингредиентов в русских текстах рецептов. Два подхода:
словарь справочника с лемматизацией и дообученный
[`cointegrated/rubert-tiny2`](https://huggingface.co/cointegrated/rubert-tiny2).
Модель учится на разметке словаря (distant supervision), проверяется на ручной.

## Результаты

Test — 50 рецептов, 832 упоминания, ручная разметка; оценён один раз.
Модели выбраны заранее по dev (40 рецептов): C7 — лучшая по F2 аллергенов,
B13 — лучшая по F1 упоминаний.

**Упоминания:** P, R, F1 по отрезкам, точное совпадение границ; интервал —
бутстреп по рецептам.

| Система | P | R | F1 | 95% интервал |
|---|---|---|---|---|
| словарь | 0.744 | 0.882 | 0.807 | [0.774, 0.839] |
| словарь + фильтр по составу | 0.979 | 0.744 | 0.846 | [0.812, 0.879] |
| модель B13 | 0.943 | 0.831 | **0.883** | [0.860, 0.907] |
| модель C7 | 0.791 | 0.882 | 0.834 | [0.808, 0.862] |

- B13 − словарь: +0.076 [+0.048, +0.106]; B13 − словарь с фильтром: +0.037
  [+0.017, +0.060]. Обе разности значимы (парный бутстреп).
- Фильтр смотрит в состав рецепта, модель — только в текст.

**Аллергены блюда:** пары «блюдо, аллерген», уровень предупреждения; пропуск
— доля блюд, где хоть один аллерген остался без предупреждения.

| Система | P | R | F2 | 95% интервал | F2 «содержит» | Пропуск |
|---|---|---|---|---|---|---|
| словарь | 0.418 | 1.000 | 0.782 | [0.724, 0.830] | 0.874 | 0.0% |
| словарь + фильтр по составу | 0.480 | 0.878 | 0.753 | [0.699, 0.805] | 0.737 | 24.4% |
| модель B13 | 0.482 | 0.959 | 0.801 | [0.746, 0.846] | 0.765 | 9.8% |
| модель C7 | 0.419 | 0.992 | 0.779 | [0.724, 0.824] | 0.860 | 2.4% |
| эталонные отрезки | 0.484 | 0.967 | 0.806 | [0.753, 0.848] | 0.765 | 9.8% |

- Все разности F2 незначимы. Модель с идеальными отрезками (последняя строка)
  не лучше B13: потолок задаёт не поиск упоминаний.
- Точность 0.42–0.48: общие слова («мука», «масло») связываются с
  несколькими позициями справочника, и система предупреждает обо всех их
  аллергенах как «может содержать».
- Статусы на эталонных отрезках test: `absent` — полнота 0.15, `optional` —
  0.49. Словарь триггеров собирался на dev и переобучился на нём.

Словарь по леммам находит в тексте 84,0% ингредиентов состава, без
лемматизации — 49,9% (`scripts/coverage.py`).

## Варианты обучения

Метки train — находки словаря после фильтра по составу; общее название
(«мясо», «овощи») связывается с частными из состава (`generic_names.json`).
Отброшенное фильтром:

| Вариант | Отброшенное | dev F1 упоминаний |
|---|---|---|
| A | ингредиент | 0.752 |
| B | не ингредиент | 0.835–0.848 |
| C | вне потери (−100) | 0.786–0.796 |

## Данные

- [rogozinushka/povarenok-recipes](https://huggingface.co/datasets/rogozinushka/povarenok-recipes):
  названия и составы, 146 582 рецепта.
- Тексты — со страниц povarenok.ru, 14 761 рецепт. Права на тексты у сайта, в
  репозитории их нет.
- Ручная разметка: test — 50 рецептов, 832 упоминания; dev — 40 рецептов.
  Правила — [docs/annotation.md](docs/annotation.md).

Данные — в `data/` или в папке из переменной `INGREDIENT_NER_DATA`.

## Конвейер

| Скрипт | Результат в `data/` |
|---|---|
| `prepare_recipes.py` | `recipes_prepared.jsonl` |
| `crawl.py` | `scrape_log.jsonl`, `pages/` |
| `assemble_texts.py` | `recipes_with_texts.jsonl` |
| `build_canon.py` | `ingredient_canon.json` |
| `build_ner_data.py` | `ner/{train,dev,test}.jsonl` |
| `train.py --variant B --seed 42` | `models/variant_B_seed42/` |
| `evaluate.py --split dev --model variant_B_seed42` | таблица метрик |
| `evaluate_allergens.py --split dev --models variant_B_seed42` | аллергены блюд: F2, доля блюд с пропуском |
| `demo.py --model variant_B_seed13` | страница на `127.0.0.1:8000` |

## Модель

Веса в репозиторий не входят: 116 МБ, больше лимита GitHub на файл. B13
обучается заново, около 7 минут на RTX 2060, по данным из раздела «Данные»:

```
python scripts/train.py --variant B --seed 13
```

## Страница для проверки

```
python scripts/demo.py --model variant_B_seed13
```

На `http://127.0.0.1:8000` — поле для текста блюда. Найденные ингредиенты
подсвечиваются по статусу (в блюде / по желанию / нет в блюде), при наведении
видны позиции справочника и их аллергены; ниже — аллергены блюда: «содержит» и
«может содержать».

![Страница с разобранным текстом](docs/demo.jpg)

## Пакет

| Модуль | Что внутри |
|---|---|
| `recipes` | очистка рецептов, канонические названия |
| `scraping` | разбор страниц, обход, сборка текстов |
| `dictionary` | поиск по леммам, фильтр по составу |
| `bio` | BIO-метки, выравнивание с подсловами |
| `dataset` | записи NER, проверка разметки, почти-дубли |
| `ner` | кодирование, обучение, предсказание |
| `metrics` | P/R/F1 по отрезкам, бутстреп |
| `context` | статус упоминания: present, optional, absent (NegEx / ConText) |
| `allergens` | связывание со справочником, таблица аллергенов, `analyze` |
| `dish_metrics` | метрики по аллергенам блюда: два уровня, F2, бутстреп |
